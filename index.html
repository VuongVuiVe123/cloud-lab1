02 Cloud Computing

Cloud computing is a way of using computing resources such as servers, storage, databases and networking through the internet instead of owning and maintaining physical hardware ourselves. A provider runs large data centers, and customers rent only the capacity they need, paying according to their actual usage. This model brings many benefits: resources can be created within minutes, applications can scale up when traffic grows and scale down when it drops, and the costs of buying and maintaining equipment are greatly reduced. Cloud services are also available from anywhere with an internet connection, which makes teamwork and global access much easier for individuals, companies and schools.

03 Cloud Services

IaaS

Infrastructure as a Service provides virtual machines, storage and networks. The user manages the operating system and applications.

Examples: Amazon EC2, Microsoft Azure Virtual Machines, Google Compute Engine.

PaaS

Platform as a Service provides a ready-made environment to build and run applications without managing servers or the operating system.

Examples: AWS Elastic Beanstalk, Google App Engine, Heroku.

SaaS

Software as a Service delivers complete applications over the internet that users simply open and use in a browser.

Examples: Google Workspace (Gmail, Docs), Microsoft 365, Dropbox.
